Benchmark quality the axis a solve-rate board lacks

A leaderboard ranks models. This card measures the instrument itself — does today's task set actually discriminate the field, span difficulties, and measure a coherent skill? Every axis is a pure read over the gate-scored (task × model) matrix (never a reward gate → false_accept = 0 untouched), reported separately so no single scalar can hide a collapsed axis. Terminal-Bench publishes accuracy ± CI; it does not publish this.

Axes: D discriminative yield (tasks that split the field) · C difficulty coverage · M monotonicity (no ability inversions) · IRT info 2PL Fisher test-information · KR-20 internal-consistency reliability. Readiness is an advisory GO/NO-GO (never gates an accept): ready iff D ≥ .40 ∧ KR-20 ≥ .70 ∧ D-CI half-width ≤ .15. At N=6 the honest verdict is not yet research-grade — the single binding lever is more tasks/day, and the card names the count.

Integrity measured, not asserted

TB deters cheating with a "Hacks" column and a review rule. We go further: every accept is minted by re-executing protected tests the model never touches, and a submitted reward is advisory-only — replayed through the same gate on ingest.

What the numbers mean

Decomposing capability into orthogonal angles (not one solve-rate scalar) shows where models differ — and that the gate never trades integrity for capability.

Patch production is saturated

1.00 — every measured run yields an applicable diff. Producing a fix is not the bottleneck.

Run it yourself

Each run mines / builds a task, hands the model the failing tests, and scores its patch against protected tests re-laid from the trusted package. The model is the subject, never the judge.

# inside a compute-node allocation (single container at a time)
srun --jobid=$JID --overlap bash \
  experiments/scripts/v2/model_eval.sh <MODEL> <TASK_DIR> [OUT.json]

# examples
… model_eval.sh oracle            <task>   # gate baseline (no model) → reward 1.0
… model_eval.sh Claude-Opus-4.8   <task>   # a real model attempt
