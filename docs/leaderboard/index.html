benchmark quality

the axis a solve-rate board lacks quality card →

A leaderboard ranks models. This card measures the instrument: does today's task set discriminate the field, span difficulties, and measure a coherent skill? Each axis is a pure read over the gate-scored (task × model) matrix — never a reward gate, so false_accept = 0 is untouched — and each is reported separately so no scalar can hide a collapsed axis.

run it yourself

Each run hands the model the failing tests and scores its patch against protected tests re-laid from the trusted package. The model is the subject, never the judge.

# inside a compute allocation (single container at a time)
srun --jobid=$JID --overlap bash \
  experiments/scripts/v2/model_eval.sh <MODEL> <TASK_DIR> [OUT.json]

# examples
… model_eval.sh oracle          <task>   # gate baseline (no model) → reward 1.0
… model_eval.sh Claude-Opus-4.8 <task>   # a real model attempt
