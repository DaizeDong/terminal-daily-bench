Scaffold adapters

Plugging in your own scaffold.

The adapter contract

The built-in scaffold is single_shot_patch, one localized shot at a diff. Multi-turn agents plug in via the adapter contract, over any OpenAI-compatible endpoint.

What an adapter may not do

produce_patch(...) must NOT read or write the protected tests or the gold solution, and must not compute a reward.

The execution gate stays the sole reward authority as harnesses are added. Semantic false-accept still requires labeled exploit trials.
