Agent integration

Connect your agent while keeping evaluation consistent.

What an agent provides

An integration receives a task, model connection settings, and available failing-test names. It returns a proposed code patch and basic run information. The built-in baseline requests one patch; other agents may use multiple steps.

See Connect an agent for implementation guidance.

Keep evaluation separate

An agent must not read or modify the protected tests or reference solution, and it must not assign its own score. The evaluator runs the tests after the agent finishes. Use the same agent configuration when comparing models.
