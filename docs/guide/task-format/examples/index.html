Examples

Common commands for inspecting tasks and working with results.

Install and check

From a project checkout, install the tools and check a task directory. Replace the example path with your local task.

Run an archived task

Scoring requires the unpublished evaluation environment. With it available, check the reference solution, then evaluate your model.

Inspect a live task

You can read a live task without running the evaluator. The test names are public; the assertions and reference solution are withheld.

Prepare a task for publication

Task authors can export a package with the appropriate live or archived contents. See the package reference for publication instructions.

Contribute a result

Prepare the model and agent details with the patch, then follow Submit results. Submitted scores remain pending until operators have evaluated the patch.
