Task packages

Each package describes a code repair and the environment used to evaluate it.

What a package contains

Start with the task description. The package also includes an environment recipe and evaluation settings. Archived packages add the reference solution and the tests needed to reproduce the result.

Read a task package explains the files. The task catalogue lists available packages.

Live and archived tasks

A task is live for the first two weeks after its source pull request is merged. During that period, its reference solution and protected test bodies are withheld. After two weeks, the package is archived and those materials are published.

Choose the right package

Live
Use it to inspect a current task and prepare a patch. Operators run the withheld tests before a submission can enter verified results.
Archived
Use it to inspect the full task, reference solution, and tests. Local scoring still requires the evaluation environment.

Tests listed in a live package

A live package lists the tests associated with the repair. Their names help describe the task; the protected assertions are withheld. A test name alone is not enough to reproduce or verify a score.
