Task format

Self-contained, harbor-native packages under tasks/{archive|live}/<task-id>/.

Package layout

Everything here reflects the code in this bundle; no APIs are invented. Task ids look like td-fc90ea8b76d5f6b6.

The canonical short schema is tasks/SCHEMA.md; the code is terminal_daily_bench/, tasks/publish_tasks.py and web/submit_result.py.

The schema above is the whole contract — a task directory is valid on its own. Published task directories are listed in the task registry, one row per task id, with its release mode and its failing-test count.

Archive vs. live

A task is archived two weeks after its source PR merged. Live withholding blocks memorization and test-editing; releasing archived tasks in full supports local reproduction.
