What the gate does and does not cover

Scope
Proves replay integrity, not semantic verifier completeness.
Test edits
A patch that edits tests/ only changes the discarded run-copy workspace — the protected tests come from the trusted package, not the patch.
Reward source
harbor_score.read_harbor_reward, the same reader the private admission gate uses.
BAD-safe
No patch, a failed apply, a hung trial or an unparseable result yield reward 0.0 / solved: false, cause recorded — never a positive score on a crash.
Offline cut
Offline tasks get the no-network switch from harbor_score.maybe_inject_offline_eks (singularity-gated, task-driven, idempotent).
Host hygiene
harbor_score.clean_subprocess_env scrubs host conda/venv pollution.

Per-run result record

One JSON object per run, recording the reward and what the gate did and did not check.
