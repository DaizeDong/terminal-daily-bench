Scoring limits

Passing the tests supports a result, but does not prove that every solution is correct.

What is checked

The evaluator records whether a result came from running the protected task tests. A submitted score or a model’s claim of success is insufficient.

Who decides the outcome

The model proposes a patch. The evaluator restores the trusted tests before running them, so edits to the model’s copy of the tests do not determine the result. Submitted patches are checked by the operators before entering verified results.

What remains unknown

Protected tests may still miss an incorrect or deliberately misleading solution. The rate at which such solutions pass has not yet been measured. Checks that a run followed the evaluation procedure cannot establish that the tests cover every failure mode.
