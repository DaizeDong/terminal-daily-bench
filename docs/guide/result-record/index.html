The result record

What one run writes, and the three fields you will actually read.

What one run writes

Each run writes one JSON record. A solved run looks like this.

The three fields you will read

scaffold
single_shot_patch for a model run, oracle_baseline for tdb oracle.
reward
The protected-test outcome. solved is reward >= 0.999.
patch_applied
true once a reward is parsed, false if the patch failed to apply, null if the gate never reached the apply step.

Failure never scores

Runs are BAD-safe: any failure yields reward = 0.0 and solved = false, with the cause in error.

That covers no diff, a patch that does not apply, a hung trial and an unparseable result. There is never a positive score on a crash.

What that reward does and does not certify is the false-accept check.
