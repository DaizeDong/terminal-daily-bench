Read the quality report

Use the report to inspect the evidence behind a comparison.

Start with scope and coverage

The quality report presents provisional measurements from the available results. Check which date, tasks, models, and agent configuration each figure covers. A figure for one configuration does not describe every run in the benchmark.

A blank or hollow cell is not automatically a failed attempt. Read the figure’s coverage note. Overlapping confidence intervals alone are not a test of statistical significance.

Compare like with like

Keep publication mode and evaluation conditions consistent. Live and archived packages differ in what they reveal; that distinction does not itself establish task difficulty. Author-assigned difficulty is also separate from measured success rate.

Capability labels overlap, and tasks from the same project may be related. These reports help inspect a task set; they do not certify a model ranking.
