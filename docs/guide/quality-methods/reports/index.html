Reading the discrimination report

Standing methodology for the selection-quality report, so it does not have to sit beside every figure.

What the numbers on that page are

Provisional readings
Provisional readings, not properties — every number on that page is recomputed from the published matrix at page load.
Scaffold scope
The solve matrix is one scaffold, one model family, one day. It is never the whole model suite, and its cells are not independent trials.
Hollow squares
A hollow square is a task from another suite, not a skipped run. Where a run really was skipped under the reported scaffold, the note on the figure says so instead and names the count.
Overlapping intervals
Overlapping Wilson intervals are not a significance test. Where a figure paints a shaded band, that band marks the range every count in that group still allows.

Which rows may be compared with which

The level rows
The difficulty rows are a partition of the publication-mode row above them, not peer groups. They are compared inside one publication mode only: pooling the modes puts structurally-zero tasks into the comparison and the result is an artifact of pooling.
Publication mode
Live vs archive is a difference in what is withheld, not measured difficulty. Live withholds gold patches, protected test bodies and merge provenance; archive publishes them. Harder, newer and measured differently cannot be told apart. Any other publication mode likewise differs in what the task package publishes, so those rows are coverage facts, not difficulty findings.
Declared difficulty
Declared difficulty is editorial — the task.toml label, never measured.
Authority
Nothing on that page is ranked or certified: no publication bundle is approved, no matrix digest is trusted, and receipt authority is inactive — which is why the registry’s Official solves column is a dash.
