Analyze results in Python

Use Python when you need to inspect or extend the quality analysis.

Compute a summary

Prepare a complete rectangular JSON array, with one row per task and the same models in the same column order on every row. Include only tasks with an evaluated outcome for every model. Exclude incomplete tasks and report those exclusions. Use one for a pass and zero for a failure.

Use at least one task and two models. For ordinary run files, the command-line analysis handles the input format for you.

Explore task subsets

The Python tools can select subsets by discrimination, difficulty coverage, information, or diversity. Use them to study task-set design, and report how selection was performed. Selecting and evaluating on the same outcomes can make a comparison look stronger than it generalizes.

Exact arguments and return values are in the Python reference.
