The quality API

One call that aggregates every axis, and the selection helpers beside it.

One-call quality card

benchmark_quality_report(matrix, ..., deep=True) aggregates every axis: msq (the D/C/M profile plus composite), diversity from signatures, angle coverage from the flat graded states, noisy_task_indices (monotonicity violations), and a curated subset (monotonic core → info-max → diverse filter). Under deep=True it adds IRT (total_information + SE), ci bootstrap intervals, power precision required-N, reliability KR-20, and reliability_prophecy Spearman-Brown required-k.

Selection helpers

select_informative_subset
Greedy D + C.
select_max_information
Top-k Fisher.
balanced_subset
Difficulty-balanced.
diverse_subset
Farthest-point over signatures.
select_mid_difficulty
Scaffold-relative discriminative band.
filter_monotonic / flag_noisy_tasks
Drop ability-inverting tasks.
cross_scaffold_quality
Most discriminative scaffold frame.
