Selection-quality methods (MSQ)

Multi-angle Selection-Quality — how well a task set discriminates models, scored from a graded (task × model) matrix.

The matrix convention

Solved means grade >= solved_threshold (default 1). Binary 0/1 and graded 0..K both work, and the CLI builds the matrix for you.

What enters the matrix

A run produces a status before it produces a grade. Only an authenticated SUCCESS with score_accepted=true becomes a numeric outcome; SUCCESS with score_accepted=false, FAILED, BLOCKED and NOT_RUN all record outcome:null. All five statuses are counted in coverage.

Null is not zero. Those rows are not converted to zero and are excluded from ratings, because a task that could not be attempted is not a task the model failed — zeroing them would move a harness outage into the model’s score. They are counted in coverage, not outcomes, so a model that ran few tasks shows low coverage rather than a clean-looking rate.

Two tallies, never summed

A declaration cannot authenticate its own status, so the two tallies are never summed.

authenticated_counts
Bound to receipts.
untrusted_declared_counts
Bound to what a submission asserted about itself.

Which dimensions may be ranked

Three dimensions, each bound by the trusted task catalogue. ALLOWED_DIMENSIONS enforces the list in code, and a dimension outside it is not rendered. Unavailable and zero are different claims.

overall
Rankable.
language
Rankable.
capability
Authorised. The C1–C14 labels are published on every archive package, but no axis clears the publish gate on this catalogue.
task-family
Task-family: unavailable. Historical data carries no authority-bound family field. The site does not infer one from tracks, merged labels, or repository metadata, and does not display zero.
