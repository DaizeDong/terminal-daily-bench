D — discriminative yield

The fraction of tasks that split the field: only tasks some models solve and others miss carry information, and the rest are the blind spot. An all-pass or all-fail task therefore carries zero discrimination. With fewer than two models D is None, and its default composite weight is 0.5.

C — difficulty coverage

Normalized entropy of solve-rate bucket occupancy, over equal-width bins on [0, 1]. Tasks spread evenly give C = 1; tasks all clustered in one bucket give C = 0.

M — monotonicity

The fraction of tasks with no strong ability inversion. Compared pairs are those where ability_i > ability_j + ability_eps, with ability_eps defaulting to 0.05; a strong inversion is solved_j and not solved_i — noise, mislabel, or gameability — and a monotonic task is one with zero inversions. Ability defaults to each model’s overall solve-rate; with no ability separation M is vacuously 1.0.
