Uncertainty and required N

How wide today’s interval is, and how many tasks it would take to narrow it.

Bootstrap confidence intervals

msq_bootstrap_ci resamples the task rows with replacement, n_boot times, recomputing D/C/M on each resample. estimate is the full-set point estimate, [lo, hi] the central ci-percentile interval (default 95%), and se the bootstrap SD. The RNG is seeded, so a resume is reproducible, and at N ≈ 6 tasks the intervals are wide.

Precision-power (required-N)

required_tasks_for_precision scales SE as 1/√N from the bootstrap SE at N₀. It returns one record per axis — {axis, n_now, se_now, half_width_now, target_half_width, required_n} — where required_n is None when the axis SE is undefined and 0 when SE is already 0. precision_curve(matrix, sizes, axis="D") gives the curve [{n, half_width}, ...].

Reliability-power (required-N)

tasks_for_reliability applies the Spearman-Brown prophecy to give the test length needed to reach a target KR-20. It returns {current_kr20, current_k, target_kr20, required_k} measured from the current KR-20, with required_k None when reliability is undefined or ≤ 0, or the target is outside (0, 1).
