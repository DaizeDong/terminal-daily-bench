Uncertainty and sample size

Estimate how much the conclusion might change with a different task sample.

Confidence intervals

The analysis repeatedly samples tasks from the observed set and recomputes each measure. The resulting interval summarizes sensitivity to the task sample. Small task sets often produce wide intervals.

These intervals do not account for every source of uncertainty, such as a different model configuration or repeated-run variation.

Tasks needed for greater precision

The report estimates how many similar tasks would narrow an interval to a chosen target. The approximation assumes uncertainty decreases with the square root of the number of tasks.

Treat the estimate as planning guidance. Adding different or highly repetitive tasks may not produce the predicted improvement.

Tasks needed for greater reliability

A second estimate projects the task count needed to reach a target reliability, assuming new tasks behave like the current ones. It is unavailable when the current reliability cannot support that projection.

More tasks can help with precision, but cannot by themselves repair biased coverage or invalid tests.
