Scope, estimands and limits

What the module is, which effects it keeps apart, and what none of its numbers licenses.

Scope and limits

Module
terminal_daily_bench.quality
Pure
Pure functions over plain lists; they neither read nor change reward decisions.
Blind to
Semantic verifier false-accept — MSQ cannot measure it.
Deterministic
Randomized routines are seeded; a resume reproduces the interval.
Advisory
No MSQ number and no readiness verdict ever gates an accept.
Undefined
An axis without a population returns None, never a fabricated number.

Separate estimands

Model, harness, and complete-configuration effects stay separate estimands: a harness effect is never read as a model effect, and a configuration score is never relabelled as model-only performance.

What the card does not license

What it does catch is a collapsed set: all-pass or all-fail rows, a negatively correlating item, a missing difficulty band. What it does not license is any of the following.

A ranking is not a result.
At this N one model’s Wilson interval covers most of the others.
D is coarse at small N.
One task flipping moves it a step.
Not yet one instrument.
Below the KR-20 bar the total is not a skill estimate.
A vacuous high is not a win.
M reaches 1.0 when no separation is left to violate.
Required-N is an order of magnitude.
It assumes the next tasks are drawn like today’s; it is today’s bootstrap SE extrapolated at 1/√N.
Readiness is advisory.
It never gates an accept or touches the reward path.
