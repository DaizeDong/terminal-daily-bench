The readiness verdict

benchmark_readiness folds discrimination, reliability and precision into one daily GO/NO-GO advisory. It is ready iff all three hold.

What the verdict carries

reasons
Each failing constraint with its value, threshold and required_n. A None on any axis fails that axis.
bottleneck
The failing constraint that demands the most tasks.
recommended_n
max(precision-required-N, reliability-required-N).
Status
Advisory only: it never gates an accept.
