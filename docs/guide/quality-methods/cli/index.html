Running tdb quality

What the command reads, what it prints, and the same axes on today’s published suite.

What the command reads

It reads a results file — JSONL or a JSON list — builds the matrix, prints the quality card and then the readiness line. Each record needs task, model, and either solved or reward; solved is taken as reward ≥ 0.999, rows with model == "oracle" are excluded, and the command exits 2 below ≥ 1 task and ≥ 2 models.

On the 6-task / 3-model example. The last line is that card as JSON.
