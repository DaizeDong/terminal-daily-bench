Task coverage and diversity

Check which stages of a repair are represented and how much tasks overlap.

Stages of a repair

Where progress observations are available, coverage can distinguish building the environment, making a partial repair, passing all repair tests, and preserving tests that already passed. Each stage asks a different question about the task set.

Enough observations to interpret

A later stage can be assessed only among runs that reached the preceding stage. If too few runs reach it, the estimate is unavailable. For example, a set with no completed repair cannot show how often a completed repair preserves existing behavior.

Task diversity

Diversity estimates how much tasks overlap in source repository, changed files, and relevant tests. Many similar tasks can make a large set less informative than its size suggests.

This is a measure of task similarity, not proof of independent skills or independent observations. Read it as supporting context.
