What an evaluation does

A model proposes a code change for a task. The evaluator applies it and runs protected tests. The result records whether those tests passed.

Requirements

  • Python 3.11 or later.
  • For model calls, an OpenAI-compatible API endpoint and its credentials.
  • For scoring, an Apptainer or Singularity host and access to the required evaluation environment.

Current availability

The required evaluation environment includes unpublished changes to Harbor, the task runner. The public commands cannot yet score a task end to end without it. Installing the standard Harbor package does not provide those changes.

Task inspection, setup checks, task publication, and analysis of existing results remain available.
