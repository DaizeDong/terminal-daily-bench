Evaluate a model

Run a local evaluation before preparing a contribution.

Evaluate an archived task

These commands require the unpublished evaluation environment and a prepared task image. Check the reference solution before making a model call.

See Run a task for the complete setup.

Connect the model

Use an OpenAI-compatible provider or local model server. The model identifier must be supported by that endpoint. The reference-solution check does not call a model.

Keep the result

Save the run record with the patch and evaluation configuration. It reports the outcome and any execution error. Read a result explains how to review it.

Check unsuccessful runs

An absent patch, an application failure, or an execution error cannot earn a positive score. Check the reported cause before treating a run as evidence about model ability. A local result still requires operator validation for verified publication.

Working with live tasks

Live packages withhold the protected tests and reference solution. You can prepare a patch, but operators must run the withheld tests before the contribution becomes a verified result.

Use Task packages to distinguish live and archived releases.
