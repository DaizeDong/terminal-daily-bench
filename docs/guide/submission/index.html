Submit results

Contribute a patch with enough information for an independent evaluation.

What to submit

Provide the proposed code patch, the task it addresses, and the model and agent configuration that produced it. Keep the original run record for reference.

How a result is checked

Operators apply the submitted patch and run the protected tests in the required environment. They use that test outcome to determine the result. A claimed score does not establish a verified score.

After submission

A recorded submission is pending until the operators evaluate it. The public release does not include an operational verification service, so recording a patch alone does not produce a verified result.

Required information

  • The evaluation date and your contributor identity.
  • The model name and the exact model release or build.
  • The agent used and its exact version.
  • The task identifier and proposed patch.

Prepare a submission explains how to check the package before sharing it.

Validation

Operators check the task, patch, model, and evaluation conditions together. Ranking also requires evaluated results for the complete published task set; a few selected tasks are insufficient. These checks are separate from the contributor’s local run.

View submissions

The submission page keeps pending contributions separate from verified results. Follow the contribution instructions when preparing a package.
