what is in a task package

five files, no surprises task format →

A package holds task.toml (id, suite, language, the fail-to-pass test ids, resource limits), instruction.md (the only text the agent sees), the protected tests (kept outside the agent's workspace and re-laid over it after the patch, so editing them changes nothing), the environment (a pinned container recipe built at the PR's base commit, run with the network cut), and PROVENANCE (repo, PR number, base and merge sha, merge timestamp, upstream license). Archive tasks ship the gold patch too. Live tasks withhold it — along with the protected test bodies — so a live suite cannot be solved by reading it; those submissions are re-scored server-side by the same gate.
