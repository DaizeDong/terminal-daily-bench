Read a task package

Find the instructions, environment settings, and evaluation tests.

Task description

Read instruction.md first. It explains the requested repair. Identifying details about the source project and its change history are removed from the model-facing description.

Environment settings

task.toml describes the task environment and resource limits. Published packages point to a build recipe rather than a machine-specific image. Follow Prepare the environment before attempting a local evaluation.

Keep the task’s network and resource settings when comparing results. Changing them changes the evaluation conditions.

Evaluation tests

Archived packages include the test runner and protected assertions. These tests are restored by the evaluator after the proposed patch is applied. Live packages withhold the test bodies until archival.

For the complete file specification, see the package reference.
