Analyze a results file

Generate a quality summary from saved evaluation records.

Run the analysis

Provide a JSON Lines file or JSON array containing the run records. The command needs at least one task and two models and excludes reference-solution runs. It does not require a model connection or the task evaluation environment.

Read the output

The command reports the task and model counts, quality measures, uncertainty intervals, and a readiness assessment. It also prints the complete summary as JSON for further analysis.

Start with What the measures mean, then review Assess a task set to interpret the suggested next steps.

Published measurements

Use the current report to inspect published task coverage and quality.
