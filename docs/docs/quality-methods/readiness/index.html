Assess a task set

Use the readiness assessment to identify what needs more evidence.

Signs of a weak comparison

  • Most tasks are passed by everyone or by no one.
  • Tasks cluster in one difficulty band or repeat similar repairs.
  • Outcomes are inconsistent across tasks.
  • Intervals are too wide to support a precise conclusion.

Default assessment

The default assessment asks for a discrimination rate of at least 0.4, reliability of at least 0.7, and a discrimination interval whose half-width is at most 0.15. All three conditions must be met; an unavailable measure cannot establish readiness.

What to do with the result

The report names the limiting measure and estimates a useful task count where possible. Inspect that limitation before collecting more tasks.

Readiness is advisory. It neither validates individual scores nor authorizes a formal ranking.
