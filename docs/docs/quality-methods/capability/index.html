Capability categories

Fourteen categories describe the kinds of work a repair involves.

How to use the categories

Use a capability filter to compare performance on a particular kind of task. A task can belong to several categories, so category counts overlap. Labels describe the repair; they do not measure its difficulty.

Labels are inferred from available code changes. Live tasks may carry declared labels that cannot yet be checked against the withheld reference patch. See How tasks are labeled.
