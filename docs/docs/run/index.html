Run a task

Evaluate a model on an archived task and inspect its result.

Prepare the environment

These steps require the unpublished evaluation environment. Archived packages include a build recipe. From the project checkout, replace the task path below, build its image, and update the local task configuration.

The build needs internet access. Tasks configured for offline evaluation run without it.

Check the reference solution

Run the supplied reference solution before comparing models. It should pass the task tests; a failure calls for checking the task environment first.

The reference solution is included only in archived packages. Live tasks require operator evaluation.

Evaluate a model

Replace MODEL with an identifier accepted by your model endpoint. Save the result to a file you can inspect or analyze later.

What the baseline sees

The built-in baseline makes one model request using the task description and selected source files. Those files are selected from the reference patch, so this measures a repair with relevant files supplied, rather than unrestricted repository search. The proposed change is then tested.

Choose a task

Open the task catalogue and select an archived task. Its page explains the task and links its package.
