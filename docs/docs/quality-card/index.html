Quality summary

Assess whether a task set gives useful evidence for comparing models.

Analyze saved results

Collect the run records into a JSON Lines file, with one record per line, or a JSON array. The analysis command does not call a model or run the task evaluator.

Use comparable evaluations

The command needs at least one task and two models. Reference-solution runs are excluded. Use consistent agent settings and check task coverage before interpreting the summary.

Read the summary

Start with the number of tasks and models. Then check whether tasks distinguish models, cover a range of difficulty, and give reasonably consistent results. Wide uncertainty intervals mean the task set supports only imprecise conclusions.

Understand the measures

The summary reports discrimination, difficulty coverage, consistency, information, and reliability. Its readiness assessment is guidance about the task set, not approval of a score. Evaluation methods explains each measure.

Share an evaluation

Include the original records and configuration when submitting results. A locally computed quality summary does not replace operator validation.
