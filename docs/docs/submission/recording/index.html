Prepare a submission

Check that a contribution includes the patch and the details needed to evaluate it.

Check the submission file

Prepare a submission file using the contribution instructions. From the project checkout, validate its structure before sharing it.

Include the full evaluation details

Identify the task, model release, agent version, evaluation date, and contributor, and include the proposed code patch. Keep these details consistent with the run you are reporting. Validation checks the file format; operators must still evaluate the patch.

Keep submissions comparable

Use one model and agent configuration across the complete task set for a reported evaluation. Partial, duplicate, or mixed-date submissions do not establish a complete result. A corrected patch needs to be evaluated again.
