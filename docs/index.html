terminal-daily-bench: a benchmark that is rebuilt every day

Tasks are mined from real merged pull requests each day, so an agent cannot have trained on the fix. Every attempt is scored by execution proof only — a protected test suite the model never sees, re-laid after its patch. No LLM judge, so false_accept = 0 by construction.

what makes it different

three claims, each measurable
contamination 0.000

fresh by construction

Each day's tasks come from pull requests merged after the models shipped. Freshness is certified per task, not assumed from a date.

mined → built → sealed, daily
false_accept 0

execution is the only judge

A patch is scored by re-laid protected tests running in a network-cut container. Editing the tests changes a workspace that is thrown away before scoring.

no model ever grades a model

run it in one command

# any OpenAI-compatible endpoint; scoring needs apptainer/singularity
pip install terminal-daily-bench
export OPENAI_BASE_URL=… OPENAI_API_KEY=…

tdb run    <MODEL> tasks/archive/<task-id>   # score a model on a task
tdb oracle tasks/archive/<task-id>           # gate baseline → reward 1.0
tdb quality results.jsonl                   # the multi-angle quality card
