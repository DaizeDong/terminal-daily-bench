terminal-daily-bench: a benchmark that is rebuilt every day

Tasks are mined from real merged pull requests each day, so an agent cannot have trained on the fix. Every attempt is scored by execution proof only — a protected test suite the model never sees, re-laid after its patch. No LLM judge, so false_accept = 0 by construction.

what makes it different

three claims, each measurable
contamination 0.000

fresh by construction

Each day's tasks come from pull requests merged after the models shipped. Freshness is certified per task, not assumed from a date.

execution is the only judge

A patch is scored by re-laid protected tests running in a network-cut container. Editing the tests changes a workspace that is thrown away before scoring.

how a task is made

five steps, every one of them executed the task format →
#stepwhat happenswhat it proves
1mine a merged PR A pull request that already merged in the curated repo universe and touches a test file is pulled as a candidate. freshness
2rebuild the env The repository is rebuilt into a container at the parent commit; the fail-to-pass tests must fail there, and the gold patch must take them to reward 1.0. solvability
3seal the tests Protected assertions and the reference solution are withheld; only the failing-test IDs are published, in FAILING_TESTS.json. no leakage
4certify All 7 execution tokens must come back true — oracle_pass, nop_fail, no_mutant_escape, rerun_unanimous, env_clean, egress_clear, evidence_gate_ok. Any one missing is a reject. soundness
5ship The task joins that date's sealed suite as live, and is released whole after 14 days. reproducibility

Every step is a program that runs, not a review that happens. A candidate that fails any one of them never becomes a task — the funnel is the quality guarantee. how a suite lives →

run it in one command

# any OpenAI-compatible endpoint; scoring needs apptainer/singularity
pip install terminal-daily-bench
export OPENAI_BASE_URL=… OPENAI_API_KEY=…

tdb run    <MODEL> tasks/archive/<task-id>   # score a model on a task
tdb oracle tasks/archive/<task-id>           # gate baseline → reward 1.0
tdb quality results.jsonl                   # the multi-angle quality card
