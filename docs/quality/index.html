what each axis means

what the composite is made of

axis what it asks
reads
D Discriminative yield: tasks that split the field (0 < solvers < n_models).

[0,1]
C Difficulty coverage: normalized entropy of the per-task solve-rate buckets.

[0,1]
M Monotonicity: tasks with no strong ability inversion. Inversion: a weaker model passes what an abler one misses.

[0,1]
IRT 2PL Fisher test-information: discrimination a from point-biserial, difficulty b from solve-rate. Additive, and SE = 1/√I.

≥ 0
KR-20 Internal-consistency reliability over binary items.

≤ 1
D CI Seeded bootstrap over resampled task rows, 95% central interval.

[0,1]

how to read these axes

measured on today's suite

axis what a bad value looks like
measured
D Low D: mostly all-pass or all-fail rows. Below the min_D gate the day cannot rank anyone.

—
C C near 0: every task in one difficulty band. The set then measures one point on the ability curve.

—
M M below 1 flags flaky, mislabeled or gameable tasks. M is vacuously 1.0 when no model pair is clearly separated.

—
I Information concentrated in one or two items. An all-pass or all-fail task contributes almost none of it.

—
KR-20 Below the bar (min_kr20) the set is not yet one instrument. A negative KR-20 means items contradict each other.

—
A An angle with fewer than min_support tasks in its conditioning population is undefined.

advisory
R Low R: the day filled with near-clones of one PR family. Two tasks in the same repo above the similarity cut count as duplicates.

how to read these numbers

what this card does not license

A ranking is not a result.
At this N one model’s Wilson interval covers most of the others.
D is coarse at small N.
One task flipping moves it a step.
Not yet one instrument.
Below the KR-20 bar the total is not a skill estimate.
A vacuous high is not a win.
M reaches 1.0 when no separation is left to violate.
Required-N is an order of magnitude.
It assumes the next tasks are drawn like today’s.
Readiness is advisory.
It never gates an accept or touches the reward path.

It catches a collapsed set: all-pass or all-fail rows, a negatively correlating item, a missing difficulty band.
