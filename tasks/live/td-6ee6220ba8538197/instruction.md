#### Brief description of what is fixed or changed

While working on Bioche substitutions, Codex noticed that rational integration in `ratint` could be sped up. It seems that the flag set to `False` was introduced in 2010 to address domain-inference issues that no longer appear to apply, and now unnecessarily forces the slower `EX` domain.

For example, after the change:

```python
In [2]: f = 1/((z**4 + z + 1)*x**4 + (z**3 + 2*z**2 + 1)*x**3 + (z**4 + z**2 + 1)*x**2 + (z**3 + z + 1)*x + z**2 + 1)

In [3]: %time ratint(f, x)
CPU times: user 5.54 s, sys: 875 μs, total: 5.54 s
Wall time: 5.55 s
```

Before this change, the same example would remain stuck.
